
# Mini Todo

A tiny, dependency-free todo list demo built with plain HTML, CSS and JavaScript.

## Demo

- Open the app in your browser: [index.html](javascript/mini-todo/index.html)

## Features

- Add, complete, and remove todos
- Persistent state (stored in browser `localStorage`)
- Minimal, readable code for learning and tinkering

## Files

- [index.html](javascript/mini-todo/index.html) — markup
- [style.css](javascript/mini-todo/style.css) — styles
- [script.js](javascript/mini-todo/script.js) — app logic

## Usage

1. Open `index.html` directly in a browser, or serve the folder with a simple HTTP server:

```bash
# using Python 3
python -m http.server 8000

# then open http://localhost:8000/javascript/mini-todo/
```

2. Add todos, mark them complete, or delete them — changes persist in your browser.

## Development

- No build step required. Edit `script.js` and `style.css` and reload the page to see changes.
