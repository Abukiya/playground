# Python List Practice

This folder contains a beginner-friendly practice script for Python lists: [`list.py`](list.py).

## What is covered

- Creating lists
- Accessing items with positive and negative indexes
- Slicing lists
- Updating values
- Inserting items with `insert()`
- Adding items with `append()` and `extend()`
- Removing items with `remove()`, `pop()`, `del`, and `clear()`
- Looping through a list with `for`
- Looping by index with `range(len(...))`
- Filtering with list comprehension
- Sorting with `sort()` and `sort(key=...)`
- Reversing with `reverse()`
- Copying with `copy()`
- Joining lists with `+`

## How to run

Run the script directly to see each example in order:

```bash
python list.py
```

## Notes

- Each example uses a fresh list so one operation does not affect the next one.
- The file is intentionally simple and is meant for practice and quick reference.
