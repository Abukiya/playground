# Python Intro

This folder contains a beginner-friendly Python practice script: [`intro.py`](intro.py).

## What is covered so far

- Printing output with `print()`
- Variables and assigning values
- Assigning multiple variables in one line
- Unpacking values from a list
- Printing multiple values together
- String concatenation
- Global variables and local variables
- The `global` keyword
- Common Python data types
- Numeric types: `int`, `float`, and `complex`
- Type conversion between numbers
- Random numbers with `random.randrange()`
- String basics
- Multiline strings
- String slicing
- String concatenation with examples
- String formatting with f-strings and `.format()`
- Escape characters
- Common string methods

## Example file

Run the script directly to see each example in action:

```bash
python intro.py
```

## Notes

- This is a learning file, so the examples are intentionally simple.
- The script can be extended with more Python basics such as lists, tuples, dictionaries, conditionals, loops, and functions.
