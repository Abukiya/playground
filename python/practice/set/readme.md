# Python Set Practice

This folder contains a beginner-friendly practice script for Python sets: [`set.py`](set.py).

## What is covered

- Creating sets
- Looping through a set
- Adding items with `add()`
- Adding multiple items with `update()`
- Removing items with `remove()` and `discard()`
- Removing a random item with `pop()`
- Clearing a set with `clear()`
- Set comprehension
- Joining sets with `union()` and `update()`
- Comparing sets with `intersection()`, `difference()`, and `symmetric_difference()`
- Updating sets with `intersection_update()`, `difference_update()`, and `symmetric_difference_update()`
- Working with `frozenset()`

## How to run

Run the script directly to see each example in order:

```bash
python set.py
```

## Notes

- Each section uses fresh set values so the examples stay independent.
- The file is intentionally simple and is meant for practice and quick reference.
