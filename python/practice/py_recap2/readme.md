# Python Recap 2

This folder extends the first Python recap with a broader set of beginner topics.

## Covered Topics

- Boolean values and truthy/falsy checks
- Arithmetic, comparison, logical, membership, and identity operators
- Lists with indexing, slicing, and mutation
- Tuples and unpacking
- Sets and basic set operations
- Dictionaries and key lookups
- Conditional logic with `if`, `elif`, and `else`
- `for` loops and `while` loops
- Simple functions with return values

## Main File

- [`intro2.py`](intro2.py) contains the runnable examples and printed output.

## Run It

```bash
python intro2.py
```

## Suggested Practice

- Change the sample values and predict the output before running the file.
- Add more list, tuple, or dictionary examples after each section.
- Try writing your own function that accepts two arguments and returns a value.
